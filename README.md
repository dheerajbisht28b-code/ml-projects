Welcome to my Machine Learning Practice Repository.

This repository documents my learning journey in Machine Learning, where I build end-to-end projects using different ML models as I learn them.

The goal is not just to learn the theory behind each algorithm, but to understand how it is used in a practical machine learning workflow — from data preprocessing and EDA to model training, evaluation, and deployment.

🎯 What This Repository Covers

For each model or concept I learn, I try to build a practical project around it.

The typical workflow includes:

- 📊 Exploratory Data Analysis (EDA)
- 🧹 Data Cleaning & Preprocessing
- ⚙️ Feature Engineering
- 🔄 Scikit-learn Pipelines
- 🤖 Model Training
- 📈 Model Evaluation
- 🔍 Model Interpretation
- 🚀 Streamlit Deployment
